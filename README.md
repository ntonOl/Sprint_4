# QA-scooter tests

Автотесты для сервиса https://qa-scooter.praktikum-services.ru/.
Покрывают следующие сценарии:
* При нажатии на каждый пункт выпадающего списка в разделе "Вопросы о важном" появляется соответствующий текст.
* Заказ самоката с точкой входа через верхнюю кнопку "Заказать".
* Заказ самоката с точкой входа через нижнюю кнопку "Заказать".
* Переход на главную страницу Самоката при нажатии на логотип Самоката.
* Переход на главную страницу Яндекса при нажатии на логотип Яндекса.
* Ошибки для всех полей формы заказа.
* Переход на страницу статуса заказа при вводе неправильного номера заказа. Отображение надписи, что такого заказа нет.


## Технологии

* Java 11 
* JUnit 4.13.2 
* maven 3.9.12
* selenium 4.41.0 
* hamcrest 2.2

## Запуск

Запустите тесты с помощью Maven. Для этого введите в терминале команду `mvn clean test`.
